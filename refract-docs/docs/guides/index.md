# Guides

**Tutorials** teach by building a complete small app from start to finish. Do them in order if you are new to Refract.

| Tutorial | You'll learn | Time |
| --- | --- | --- |
| [Build a counter app](./counter-app.mdx) | Components, local state, events, derived values | 15 min |
| [Build a todo list](./todo-list.md) | Data fetching with optics, loading and error states, lists | 30 min |
| [Add a global theme](./global-theme.md) | Global refractions, persistence, syncing with the DOM | 20 min |

**How-to guides** solve one problem and assume you know the basics.

| Guide | Problem it solves |
| --- | --- |
| [Animations](./animations.md) | Animate values and elements declaratively |
| [Streams and live data](./streams.md) | Show WebSocket or server-sent event data |
| [Testing components](./testing.md) | Write fast, reliable component tests |
| [Migrating from React](./migrating-from-react.md) | Translate React patterns to Refract |
