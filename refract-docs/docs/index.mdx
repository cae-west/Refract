# Introduction

Refract is a JavaScript framework for building user interfaces. You write components as plain functions that return JSX, and you keep state in refractions. When a refraction changes, Refract re-renders the components that read it and leaves the rest of the page alone.

```jsx title="Counter.jsx"
import { createComponent } from "refract";

export const Counter = createComponent(({ lens }) => {
  const count = lens.useRefraction(0);

  return (
    <button onClick={() => count.set(count.value + 1)}>
      Clicked {count.value} times
    </button>
  );
});
```

This example uses the three ideas that come up on almost every page of these docs:

- A component is a function wrapped in `createComponent()`. It returns JSX and shouldn't have side effects of its own.
- A refraction holds a piece of state. Reading `count.value` during render subscribes the component to it, and calling `count.set()` changes it.
- A lens is the object each component receives. State created with `lens.useRefraction()` belongs to that component and is removed when the component unmounts.

## What's included

Besides components and refractions, Refract provides:

- Optics, which are functions for sharing logic between components. Components that use the same optic with the same inputs share one subscription.
- Three effect hooks: `useEffect`, `useOptic` and `useFlash`. Each runs at a different point after rendering, and all of them are cleaned up when the component unmounts.
- `useTransition()` for animating values when state changes.
- `fromStream()` for turning WebSockets, server-sent events and other streams into state.
- A compiler, run through the Vite plugin, that removes reactivity your app doesn't use.

## Coming from React

Components, JSX and hook-style functions work much the same way in Refract. The main difference is how updates happen.

In React, a state change re-renders the component and its children unless you prevent it with `memo` or `useCallback`. In Refract, only the components that read the changed refraction re-render, so you don't need those tools.

`useRefraction()` returns a single object with `.value` and `.set()` instead of a `[value, setter]` pair. You can pass that object to other components and they can both read and update it.

A refraction can be local or shared. One created through a lens belongs to that component. One created at the top level of a module is shared by everything that imports it.

If you've used Solid.js signals or Svelte stores, refractions work in a similar way. [Migrating from React](./guides/migrating-from-react.md) lists React features next to their Refract equivalents.

## Prerequisites

You should know modern JavaScript, including modules, arrow functions, destructuring and promises, and have a basic understanding of HTML and the DOM. Knowing JSX helps but isn't required.
